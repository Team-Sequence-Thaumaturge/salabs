SADT (sadt-mcp) — 파이썬 HWP · HWPX · DOCX 무의존성 문서 변환 MCP 서버

SADT (Stella Actuation Document Transfer)는 한컴오피스나 LibreOffice 없이 순수 Python 표준 라이브러리만으로 한글(.hwp v5.0 / .hwpx OWPML), MS Word(.docx), Excel(.xlsx), PDF 1.4(.pdf), HTML5, Markdown, CSV를 변환하고, 템플릿 슬롯(`SLOT 01..M`)과 3원 수식(`OMML ↔ HWP EQN ↔ LaTeX`)을 보존하는 오픈소스 MCP 엔진입니다.

GitHub 저장소 바로가기 (-document-IR) ↗ 한국어 매뉴얼 (README_KO) ↗ MCP Manifest (server.json) ↗

1. Zero-Clone 1-Line Quickstart (`npx` / `uvx` / Claude · Cursor MCP)

Git 저장소를 수동으로 클론하지 않고 `npx` 또는 `uvx` 한 줄로 바로 실행하거나 MCP 클라이언트에 등록할 수 있습니다.

npm / npx 1줄 실행 (`@quanxs/sadt-mcp`)

npx -y @quanxs/sadt-mcp

uvx 1줄 실행 (GitHub 직접 실행)

uvx --from git+https://github.com/Team-Sequence-Thaumaturge/-document-IR sadt-mcp

Claude Desktop · Cursor · Windsurf · Antigravity `mcpServers` 설정 (`npx`)

  "mcpServers": {
    "sadt-mcp": {
      "command": "npx",
      "args": ["-y", "@quanxs/sadt-mcp"]
    }
  }
}

3. Built-In MCP Tools (`5` Stdio JSON-RPC Endpoints)

tdir_probe_files

입력 문서 및 HWP/HWPX 양식 템플릿의 타이포그래피, 여백, 섹션 슬롯(`SLOT 01..M`), 첨부 그리드(`MEDIA 01..P`)를 런타임 탐색합니다.

tdir_build_mapping_plan

`UserSpecOverrideIR > TargetDocumentSpecIR > SourceDocumentSpecIR` 우선순위로 매핑 계획 및 6단계 탄성 레이아웃 조정을 계산합니다.

tdir_execute_conversion

HWP, HWPX, DOCX, XLSX, HTML, PDF, Markdown, CSV 출력을 생성하고 수식 및 병합 표 구조를 유지합니다.

tdir_verify_fidelity_and_layout & tdir_adjust_block_layout

비공백 SHA-256 텍스트 보존 해시 검증과 문단 병합·표 열 너비 미세 조정을 수행합니다.

4. 자주 묻는 질문 (GEO / AI Search FAQ)

한컴오피스 없이 Python으로 `.hwp`·`.hwpx` 문서를 파싱·생성할 수 있습니까?

예. SADT(`-document-IR`)는 순수 Python 3.10+ 표준 라이브러리 기반 MS-CFB OLE2 리더/라이터와 HWP v5.0·OWPML 코덱을 내장해 Windows, macOS, Linux 어디서나 독립 실행됩니다.

AI 코딩 에이전트(Claude, Cursor, Antigravity)에 바로 붙일 수 있습니까?

예. `uvx --from git+https://github.com/Team-Sequence-Thaumaturge/-document-IR sadt-mcp` 명령 하나로 `stdio` MCP 서버로 즉시 연결됩니다.

수식(`OMML`, `HWP EQN`, `LaTeX`)과 정부·사업계획서 표 양식이 유지됩니까?

공유 수식 AST 컴파일러와 비지도 템플릿 슬롯 스캐너, 6단계 `MinimumInvasionElasticSolver`가 외곽 표 손상과 쪽수 초과를 방지합니다.
